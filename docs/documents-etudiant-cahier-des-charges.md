## Limites métier constatées

- Le quitus de sortie (page 36) et l’attestation d’hébergement (page 4) ne disposent pas encore d’un circuit d’émission dédié dans le projet. Un fichier déjà déposé dans le dossier reste téléchargeable ; le portail ne fabrique pas une validation administrative.
- Le contrat existant est régénéré à partir de la dernière attribution confirmée ; ce n’est pas encore une archive immuable de chaque contrat signé.
- Les documents communs n’ont qu’un périmètre textuel (`scope_label`), sans relation structurée à une cité. Les versions validées sont actuellement communes à tous les étudiants connectés.
- Les anciens fichiers justificatifs et les photos d’états des lieux sont stockés publiquement. Les nouvelles routes vérifient le propriétaire, mais la migration de ces fichiers vers un stockage privé reste nécessaire pour supprimer tout accès direct historique.
